Each endpoint rejected anonymous requests and invalid bearer credentials even with a valid cookie. The cookie-authenticated invitation request without `Origin` returned 403. The dashboard redirected anonymous requests and loaded with the administrator cookie. Role-less, inactive and revoked account cases remain open.

- **B-05:** Local commit `bc0f712` tracks the foundation. Local environment files and build outputs are ignored. A targeted scan found only example values and test fixtures matching secret patterns. The tracked CLI artifacts `supabase/.branches/_current_branch` and `supabase/.temp/cli-latest` still need to be excluded.

## Builder handoff rules

Take one independently verifiable increment at a time. Read `docs/README.md`, the relevant ADR, workflow/decision record and design guidance first. Report files changed, acceptance evidence, failed or unrun checks and remaining questions. Update the existing Notion task rather than creating duplicate module tasks. Do not count a screen shell, helper function or passing unit suite as a completed workflow. Record material scope changes before implementation.

## Review gates

Before operational development, verify B-01/B-06 against the documented first-demo boundary, fix foundation acceptance failures and record remaining environment limitations. Post-demo client questions are outside this gate. Before client acceptance: complete actual device, email, database and cross-workflow checks. Keep progress as capability/evidence states rather than an unsupported percentage.
