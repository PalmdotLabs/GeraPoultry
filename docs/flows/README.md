# Workflow inventory

The approved workflow specification is the detailed source of truth but is not yet stored in this repository. Until it is available, the following is a scope-level inventory plus recorded decisions, not a complete validated process map. It intentionally avoids inventing formulas, role rules, stock transitions or exception handling beyond the [workflow decision register](../decisions/workflow-decision-register.md).

## In-scope areas

1. [Flock, shed and vaccination](flock-shed-vaccination.md)
2. [Purchases, feed mill and costing](purchases-feed-mill-costing.md)
3. [Egg stock, cold storage, sales and trays](eggs-sales-and-trays.md)
4. [Payments, receivables, expenses and reports](finance-and-reports.md)

## How to complete these flow documents

For each workflow, use the approved specification and record: actor/role, starting condition, steps, required fields, validation, inventory or ledger effects, permissions, audit events, exception paths, acceptance criteria and open questions. Confirm unresolved or provisional rules before treating a flow as implementation-ready.
